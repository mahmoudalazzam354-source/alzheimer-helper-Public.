# مساعد الزهايمر — Flutter starter

هذا مشروع بداية لواجهة عربية تعمل على Android و iOS باستخدام Flutter.

## تشغيله
1. ثبّت Flutter SDK و Android Studio أو Xcode (يتطلب بناء iOS جهاز macOS مع Xcode).
2. فك ضغط المشروع.
3. من مجلد المشروع شغّل:
   - `flutter pub get`
   - `flutter run`

## الموجود حالياً
- واجهة عربية RTL.
- تبويبات الرئيسية والبحث والأغراض والعائلة والإعدادات.
- إضافة أغراض محلياً داخل الذاكرة أثناء تشغيل التطبيق.
- البحث النصي في بيانات تجريبية.
- توضيح واجهات البحث الصوتي والصوري التي تحتاج ربط خدمات فعلية.

## ما لم يتم توصيله بعد
هذا ليس إصداراً إنتاجياً ولا يتصل بخادم أو حسابات حقيقية بعد. الخطوات التالية:
1. Firebase Authentication لتسجيل حساب المريض والعائلة.
2. Cloud Firestore لتخزين الأغراض وسجل المواقع والصلاحيات.
3. Firebase Storage لصور الأغراض.
4. speech_to_text و flutter_tts للأوامر الصوتية وقراءة النتائج.
5. image_picker + نموذج رؤية للتعرف على الغرض.
6. geolocator للموضع التقريبي للهاتف، وBluetooth beacons أو أجهزة تتبع متوافقة للأغراض.
7. إشعارات محلية وسحابية، واختبارات أمان وإمكانية وصول.

## تنبيه مهم
لا يعتبر التطبيق أداة تشخيص أو علاج، ولا ينبغي الاعتماد عليه وحده في سلامة المريض أو تحديد موقع الأغراض. بيانات المواقع المعروضة هي آخر بيانات مسجلة، وليست تتبعاً مباشراً إلا بعد إضافة جهاز تتبع مناسب.
