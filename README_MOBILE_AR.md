# تشغيل مشروع مساعد الزهايمر من هاتف أندرويد فقط

## تجهيز ملف APK عبر البناء السحابي
1. أنشئ حساباً في GitHub من المتصفح على الهاتف.
2. أنشئ مستودعاً جديداً (Repository) باسم `alzheimer-helper`.
3. فك ضغط ملف المشروع على الهاتف باستخدام تطبيق الملفات.
4. ارفع محتويات المجلد إلى المستودع مع الحفاظ على البنية:
   - `pubspec.yaml`
   - `lib/main.dart`
   - `codemagic.yaml`
   - ملفات README
5. أنشئ حساباً في Codemagic، ثم اربطه بحساب GitHub.
6. أضف المستودع `alzheimer-helper` كتطبيق Flutter.
7. ابدأ workflow باسم `مساعد الزهايمر - Android test APK`.
8. بعد نجاح البناء، افتح Artifacts ونزّل `app-debug.apk`.
9. افتح الملف من التنزيلات واسمح بالتثبيت من هذا المصدر عند طلب Android ذلك.

## تنبيه
- يحتاج Codemagic إلى الوصول إلى مستودع GitHub كي يبني المشروع.
- ملف APK الناتج نسخة اختبار Debug، وليس إصداراً نهائياً للنشر.
- هذا المشروع ما زال نموذجاً أولياً: البحث النصي وإضافة الأغراض محليان وبياناتهما تجريبية.
- البحث بالصوت والصورة، مزامنة حساب المريض والعائلة، التخزين السحابي، وأجهزة التتبع لم تُربط بعد.
- لا ترفع كلمات مرور أو مفاتيح سرية إلى مستودع GitHub.
- لا تعتمد على التطبيق وحده لمراقبة سلامة المريض أو تحديد موقعه.
